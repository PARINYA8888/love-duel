# LOVE DUEL — เกมวัดใจ

เกมคำถามสำหรับผู้เล่น 2 คน เล่นออนไลน์ผ่านลิงก์หรือโทรศัพท์คนละเครื่องได้

## วิธีเล่น

1. เปิดเกมทั้งสองคนบนเบราว์เซอร์ที่รองรับ WebRTC โดยใช้ลิงก์ HTTPS
2. คนแรกใส่ชื่อ กด **สร้างห้อง** แล้วส่งรหัสห้อง 6 ตัวให้อีกคน
3. อีกคนใส่ชื่อและรหัส แล้วกด **เข้าร่วมห้อง**
4. เจ้าของห้องเลือกจำนวนคำถามและรูปแบบการเลือกคำตอบ จากนั้นทั้งคู่กด **พร้อมเล่น**
5. เมื่อทั้งคู่พร้อม เจ้าของห้องกด **เริ่มเกม**
6. ผู้เลือกตอบคำถามแบบลับ อีกคนเดาคำตอบภายใน 60 วินาที หากหมดเวลาจะเฉลยและข้อนั้นไม่มีคะแนน
7. กดไปข้อต่อไปจนครบเกม ดูคะแนนและคำตอบย้อนหลัง แล้วเล่นซ้ำได้

มีคำถาม 43 ข้อ เลือกเล่นได้ 10, 20, 30 หรือ 40 ข้อ ระบบสุ่มลำดับคำถามใหม่ทุกเกม

## เผยแพร่บน GitHub Pages

โปรเจกต์นี้เป็นเว็บแบบ static ไม่ต้องติดตั้งแพ็กเกจหรือ build เพิ่ม ให้เผยแพร่ `index.html`, `style.css` และ `app.js` จากโฟลเดอร์รากของ branch ที่ GitHub Pages ใช้ จากนั้นเปิดเว็บผ่าน HTTPS

การเชื่อมต่อผู้เล่นใช้ PeerJS, PeerServer สาธารณะ และ WebRTC แบบ peer-to-peer หน้าเว็บต้องโหลดสคริปต์ PeerJS จาก unpkg ก่อนสร้างห้อง ถ้าเครือข่ายหรือ firewall บล็อก WebRTC ผู้เล่นอาจเชื่อมต่อกันไม่ได้

ห้องและคะแนนอยู่ในหน่วยความจำของผู้เล่นระหว่างเกม ไม่มีบัญชีผู้ใช้ ฐานข้อมูล หรือการบันทึกผลหลังปิดหน้าเว็บ

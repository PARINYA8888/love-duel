# LOVE DUEL — เกมวัดใจ

เกมคำถามสำหรับผู้เล่น 2 คน เล่นออนไลน์ผ่านลิงก์หรือโทรศัพท์คนละเครื่องได้

## วิธีเล่น

1. เปิดเกมบนโทรศัพท์ของทั้งสองคนผ่านลิงก์ HTTPS
2. คนแรกใส่ชื่อ กด **สร้างห้อง** แล้วส่งรหัสห้อง 8 ตัวให้อีกคน
3. อีกคนใส่ชื่อและรหัส แล้วกด **เข้าร่วมห้อง**
4. เจ้าของห้องเลือกหมวดคำถาม จำนวนข้อ รูปแบบตอบ และธีมของคู่ จากนั้นทั้งคู่กด **พร้อมเล่น**
5. เมื่อทั้งคู่พร้อม เจ้าของห้องกด **เริ่มเกม**
6. เลือกได้ระหว่างโหมดสลับกันตอบกับโหมดตอบพร้อมกันแบบลับ ในโหมดพร้อมกันแต่ละคนตอบแทนตัวเองและเดาคำตอบของแฟนก่อนเปิดผลพร้อมกัน
7. กดไปข้อต่อไปจนครบเกม ดูคะแนนและคำตอบย้อนหลัง แล้วเล่นซ้ำได้

มีคำถาม 63 ข้อใน 6 หมวด: ความทรงจำ ความชอบ อนาคต ความสัมพันธ์ ชีวิตประจำวัน และกวน ๆ โดยเริ่มจากสามหมวดแรกและเลือกหลายหมวดพร้อมกันได้ จำนวนข้อจะปรับตามคำถามที่มีในหมวดที่เลือก ระบบสุ่มลำดับคำถามใหม่ทุกเกม

หน้าจอออกแบบสำหรับโทรศัพท์ ใช้ปุ่มขนาดใหญ่ แตะง่าย และเว้นพื้นที่ขอบจอสำหรับโทรศัพท์ที่มีรอยบากหรือแถบนำทาง เว็บติดตั้งบนหน้าจอหลักได้ และเก็บไฟล์หน้าเกมไว้เปิดดูได้เมื่อออฟไลน์ (การเชื่อมต่อเพื่อเล่นยังต้องใช้อินเทอร์เน็ต)

ห้องปัจจุบันจะถูกจำไว้ในเบราว์เซอร์ของอุปกรณ์นั้นไม่เกิน 7 วัน เพื่อกลับเข้าเล่นต่อได้หลังรีโหลดหรือหลุดจากห้อง การกลับเข้าห้องใช้ได้จากเบราว์เซอร์และอุปกรณ์เดิม ผู้เล่นกดล้างห้องที่จำไว้หรือกลับหน้าหลักเพื่อเอาข้อมูลออกได้

## เผยแพร่บน GitHub Pages

โปรเจกต์นี้เป็นเว็บแบบ static ไม่ต้องติดตั้งแพ็กเกจหรือ build เพิ่ม ให้เผยแพร่ `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `service-worker.js` และ `icon.svg` จากโฟลเดอร์รากของ branch ที่ GitHub Pages ใช้ จากนั้นเปิดเว็บผ่าน HTTPS

การเชื่อมต่อผู้เล่นใช้ Firebase Anonymous Authentication และ Realtime Database เป็นตัวกลางส่งสถานะและข้อความระหว่างโทรศัพท์ โดยเปิดใช้ long polling เพื่อรองรับเครือข่ายที่บล็อก WebSocket ได้ดีขึ้น ทั้งสองเครื่องจึงเล่นข้าม Wi-Fi และเครือข่ายมือถือได้โดยไม่ต้องเชื่อมต่อกันโดยตรง

ตั้งค่า Firebase ของโปรเจกต์นี้ไว้ใน `app.js` และกำหนดกติกาฐานข้อมูลจาก `database.rules.json` ก่อนใช้งานออนไลน์ กติกาอนุญาตให้มีผู้เล่นสองคนต่อห้อง และจำกัดการอ่านกล่องข้อความไว้เฉพาะผู้รับ คำตอบที่ยังไม่เฉลยจะเก็บไว้ในเครื่องของผู้เล่นและไม่ส่งเป็นสถานะห้อง

ห้องและสถานะเกมที่จำไว้จะอยู่ใน local storage ของเบราว์เซอร์อุปกรณ์เดิมไม่เกิน 7 วัน การกลับเข้าเล่นต่อใช้ได้จากเบราว์เซอร์และอุปกรณ์เดิม ผู้เล่นกดล้างห้องที่จำไว้หรือกลับหน้าหลักเพื่อลบข้อมูลในเครื่องได้

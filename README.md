# LOVE DUEL — เกมวัดใจ

เกมคำถามสำหรับผู้เล่น 2 คน เล่นออนไลน์ผ่านลิงก์หรือโทรศัพท์คนละเครื่องได้

## วิธีเล่น

1. เปิดเกมบนโทรศัพท์ของทั้งสองคน โดยใช้เบราว์เซอร์ที่รองรับ WebRTC และลิงก์ HTTPS
2. คนแรกใส่ชื่อแล้วกด **สร้างห้อง**
3. เลือกเกมที่ต้องการใต้รหัสห้อง แล้วส่งรหัส 6 ตัวให้อีกคน
4. อีกคนใส่ชื่อและรหัส แล้วกด **เข้าร่วมห้อง**
5. ทั้งคู่กด **พร้อมเล่น** เพื่อเริ่มเกม
6. เลือกเล่นได้ 10 เกม: เกมคำถาม, OX, เป่ายิ้งฉุบ, Cannon Duel, ใจตรงกัน, ทายเลขเป้าหมาย, แบ่งหรือเก็บ, ชิงเลข, จับคู่ความจำ และถอดรหัสอีโมจิ
7. เกมแข่งขันมีคะแนนระหว่างเล่นและหน้าสรุปผู้ชนะ เกมส่วนใหญ่เล่น 8 รอบ ส่วนจับคู่ความจำมี 8 คู่ เกมคำถามเลือกจำนวนข้อและหมวดได้ มีคลังคำถามไทย 1,000 ข้อที่สุ่มไม่ซ้ำในแต่ละเกม
8. เมื่อจบเกมเลือกเริ่มเกมเดิมใหม่โดยล้างคะแนน หรือกลับไปที่ห้องเพื่อเลือกเกมอื่นได้ ผู้เล่นอีกคนจะเห็นการเปลี่ยนหน้าจอพร้อมกัน

มีคำถาม 1,000 ข้อใน 6 หมวด: ความทรงจำ ความชอบ อนาคต ความสัมพันธ์ ชีวิตประจำวัน และกวน ๆ โดยเริ่มต้นเลือกครบทุกหมวด และเลือกปิดบางหมวดได้ จำนวนข้อจะปรับตามคำถามที่มีในหมวดที่เลือก ระบบสุ่มลำดับคำถามใหม่ทุกเกม

หน้าจอออกแบบสำหรับโทรศัพท์ ใช้ปุ่มขนาดใหญ่ แตะง่าย และเว้นพื้นที่ขอบจอสำหรับโทรศัพท์ที่มีรอยบากหรือแถบนำทาง เว็บติดตั้งบนหน้าจอหลักได้ และเก็บไฟล์หน้าเกมไว้เปิดดูได้เมื่อออฟไลน์ (การเชื่อมต่อเพื่อเล่นยังต้องใช้อินเทอร์เน็ต)

ห้องปัจจุบันจะถูกจำไว้ในเบราว์เซอร์ของอุปกรณ์นั้นไม่เกิน 7 วัน เพื่อกลับเข้าเล่นต่อได้หลังรีโหลดหรือหลุดจากห้อง การกลับเข้าห้องใช้ได้จากเบราว์เซอร์และอุปกรณ์เดิม ผู้เล่นกดล้างห้องที่จำไว้หรือกลับหน้าหลักเพื่อเอาข้อมูลออกได้

## เผยแพร่บน GitHub Pages

โปรเจกต์นี้เป็นเว็บแบบ static ไม่ต้องติดตั้งแพ็กเกจหรือ build เพิ่ม ให้เผยแพร่ `index.html`, `style.css`, `question-bank.js`, `app.js`, `manifest.webmanifest`, `service-worker.js` และ `icon.svg` จากโฟลเดอร์รากของ branch ที่ GitHub Pages ใช้ จากนั้นเปิดเว็บผ่าน HTTPS

การเชื่อมต่อผู้เล่นใช้ PeerJS, PeerServer สาธารณะ และ WebRTC แบบ peer-to-peer หน้าเว็บต้องโหลดสคริปต์ PeerJS จาก unpkg ก่อนสร้างห้อง ถ้าเครือข่ายหรือ firewall บล็อก WebRTC ผู้เล่นอาจเชื่อมต่อกันไม่ได้ คำตอบของเกมที่ต้องเลือกพร้อมกันจะถูกเปิดเผยหลังทั้งคู่ส่งคำตอบแล้ว

ไม่มีบัญชีผู้ใช้หรือฐานข้อมูล ห้องและสถานะเกมที่จำไว้จะอยู่ใน local storage ของเบราว์เซอร์อุปกรณ์เดิม และถูกลบได้จากปุ่มล้างห้องหรือกลับหน้าหลัก
